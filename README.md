# Floating Timer

A floating countdown for workshops and classrooms. Keep the time visible while presenting, teaching, or using another app. Picture-in-Picture (PiP) is especially useful on devices with restricted window management, such as iPads.

## Features

- Start, pause, reset, and quickly add time.
- Floating timer above other windows, where supported.
- Works offline after the first online visit, once the page has finished loading.
- Add to your home screen or desktop for quick access, like a PWA.
- Planned (buggy): Optional sound when time is up

## Add to Your Device

Open the timer in your browser, then:

- **Chrome / Edge:** Browser menu > Install app, if offered. Otherwise, choose Create shortcut or Add to Home screen.
- **Safari on iPad / iPhone:** Sharing button > Add to Home Screen. Turn **Open as Web App** off (the “Add as web-app” slider), then Add. PiP seems not to work in a “real” PWA; use this browser shortcut instead.
- **Safari on Mac:** Share > Add to Dock, where available. Use a normal browser window if PiP does not work.
- **Firefox:** On Android, menu > Add to Home screen. On desktop, bookmark the page; built-in PWA installation is not available (a PWA Firefox extension exists though).

Klick the rightmost button to open Timer floating above other windows. Availability and controls depend on your browser and device; some floating views are display-only.

## Development

TypeScript, plain DOM, no runtime dependencies.

```sh
npm ci
npm run build
python3 -m http.server 4173 --directory dist
```

For local use, open `http://localhost:4173`. Offline caching requires HTTPS or localhost.

The PWA supports offline use. Alternatively, you can double-click or share `dist/timer.html`. Generated by `npm run bundle`, contains all JavaScript and styling. PiP support depends on the browser.

### Architecture

Actions flow through one store into read-only snapshots shared by the page and floating views. The timer uses an absolute deadline rather than counting ticks, so delayed browser callbacks do not extend the countdown.

- `src/timer.ts`: Pure timer transitions, typed durations and timestamps.
- `src/store.ts`: State ownership, actions, subscriptions, and completion events.
- `src/scheduler.ts`: Visible animation frames and background deadline scheduling.
- `src/view.ts`, `src/styles.css`, `src/texts.ts`: Timer face, styling, and shared labels.
- `src/float/`: Floating-view lifecycle, interactive Document PiP, and canvas/video PiP fallback.
- `src/audio.ts`: Completion sound; `src/main.ts`: Application wiring.
- `src/offline.ts`, `src/service-worker.js`: Offline registration and versioned app caching.
- `build.mjs`: Produces the site in `dist/`; `npm run bundle` creates a standalone `dist/timer.html`.
- `tests/`, `e2e/`: Vitest unit/property tests and Playwright browser tests.

### Checks

```sh
npm run typecheck
npm run lint
npm test
npm run test:e2e
```

Playwright needs its Chromium browser installed (`npx playwright install chromium`). Native PiP, installation, and sound also need manual checks on target devices.
